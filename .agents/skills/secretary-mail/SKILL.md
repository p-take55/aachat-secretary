# メール対応

対象アカウント、期間またはスレッドを既知の依頼から決め、必要な範囲を読む。
一覧・検索が部分取得なら範囲と未取得分を残し、全受信箱を確認したと表現しない。
未読を要返信と同一視せず、最新の往復から誰が次に動くかを判定する。

返答が必要なメールには、相手、用件、期限、その根拠、本人にしか分からない点を付ける。
自分で回答できるものは実際の返信文を完成させる。日程や価格等を根拠なく約束しない。
複数のスレッドを一通へ混ぜず、本人の文体・署名・既存の約束を引き継ぐ。
返信先、CC、添付、スレッドを送信対象と照合する。

送信を任されていれば利用可能なツールで実行し、送信結果を確認する。
草案のみの依頼なら草案を返す。送信結果が不明なら送信履歴を確認してから再試行する。
重要度だけでメールを削除・アーカイブ・既読化しない。整理の変更は依頼された範囲で行う。

返すものは、優先する対応、返信文、処理結果、残る確認。
継続して追うものだけ、相手・用件・期限・状態・元スレッドをProjectの対応記録に残す。
